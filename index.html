🎯

The Problem

General-purpose LLMs produce inconsistent JSON when used for extraction pipelines — hallucinated keys, wrong types, missing fields, and malformed nesting that breaks downstream systems.

⚙️

The Approach

Fine-tune Mistral-7B with LoRA adapters on a curated extraction dataset, then apply DPO to align outputs toward structurally valid, schema-conformant JSON responses.

📊

The Result

A model that produces valid JSON 94.2% of the time (up from 52.9%), with correct schema adherence at 89.1%, deployable on a single A100 with 4-bit quantization.

02 / Pipeline

Training Pipeline

A two-stage process: supervised fine-tuning on labeled extraction pairs, followed by preference optimization to penalize structurally invalid outputs.

1

Dataset Preparation

12,400 (input text → JSON) pairs across 8 schema types. 80/10/10 train/val/test split. Synthetic augmentation using GPT-4 to cover edge cases.

12,400 examples · 8 schemas
↓
2

SFT with LoRA

3 epochs of supervised fine-tuning on instruction-formatted pairs. AdamW optimizer, cosine LR schedule, gradient checkpointing enabled.

3 epochs · lr=2e-4 · batch=16
↓
3

Preference Dataset Construction

Generated 4,800 chosen/rejected pairs. Rejected = outputs with schema violations, hallucinated keys, or parse failures. Verified by JSON schema validator.

4,800 preference pairs · automated labeling
↓
4

DPO Alignment

Direct Preference Optimization with β=0.1. Reference model = frozen SFT checkpoint. Training pushes log-prob ratio toward chosen responses.

1 epoch · β=0.1 · lr=5e-5
↓
✓

Merge & Evaluate

LoRA adapters merged into base model. Evaluated on held-out test set across 6 metrics. Model exported to HuggingFace Hub.

1,240 test examples · 6 metrics

# train_sft.py — Supervised Fine-Tuning with QLoRA
from transformers import AutoModelForCausalLM, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training
from trl import SFTTrainer

# 4-bit quantization config
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
)

# Load base model with quantization
model = AutoModelForCausalLM.from_pretrained(
    "mistralai/Mistral-7B-v0.1",
    quantization_config=bnb_config,
    device_map="auto",
    trust_remote_code=True,
)
model = prepare_model_for_kbit_training(model)

# LoRA adapter config
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM",
)
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# trainable params: 21,299,200 || all params: 3,829,534,720 || trainable%: 0.556

# train_dpo.py — Direct Preference Optimization
from trl import DPOTrainer
from peft import PeftModel

# Load SFT checkpoint as policy model
base_model = AutoModelForCausalLM.from_pretrained(
    "mistralai/Mistral-7B-v0.1",
    quantization_config=bnb_config,
    device_map="auto",
)
model = PeftModel.from_pretrained(base_model, "./checkpoints/sft/final")
model = model.merge_and_unload()  # merge LoRA for DPO

# Reference model (frozen SFT policy)
ref_model = AutoModelForCausalLM.from_pretrained(
    "./checkpoints/sft/final-merged",
    device_map="auto",
)

# DPO dataset format: {prompt, chosen, rejected}
# chosen  = valid JSON matching schema
# rejected = malformed/hallucinated output

dpo_trainer = DPOTrainer(
    model=model,
    ref_model=ref_model,
    beta=0.1,               # KL divergence penalty weight
    train_dataset=dpo_dataset,
    tokenizer=tokenizer,
    args=TrainingArguments(
        output_dir="./checkpoints/dpo",
        num_train_epochs=1,
        per_device_train_batch_size=2,
        gradient_accumulation_steps=8,
        learning_rate=5e-5,
        bf16=True,
        remove_unused_columns=False,
        report_to="wandb",
    ),
)

dpo_trainer.train()
dpo_trainer.save_model("./checkpoints/dpo/final")
# evaluate.py — Compute metrics across all model states
import json, jsonschema
from sklearn.metrics import f1_score

def evaluate_model(model, tokenizer, test_dataset, schema_map):
    results = {"parse_rate": [], "schema_adherence": [], "field_f1": []}

    for example in test_dataset:
        prompt = format_prompt(example)
        output = generate(model, tokenizer, prompt)

        # 1. Parse success
        try:
            parsed = json.loads(extract_json(output))
            results["parse_rate"].append(1)
        except:
            results["parse_rate"].append(0)
            continue

        # 2. Schema validation
        schema = schema_map[example["schema_id"]]
        try:
            jsonschema.validate(parsed, schema)
            results["schema_adherence"].append(1)
        except:
            results["schema_adherence"].append(0)

        # 3. Field-level F1
        pred_keys = set(parsed.keys())
        true_keys = set(example["ground_truth"].keys())
        tp = len(pred_keys & true_keys)
        precision = tp / max(len(pred_keys), 1)
        recall    = tp / max(len(true_keys), 1)
        f1 = 2 * precision * recall / max(precision + recall, 1e-9)
        results["field_f1"].append(f1)

    return {k: sum(v)/len(v) for k, v in results.items()}
